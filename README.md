# عدستي — معرض تصوير ضوئي من مكة المكرمة

موقع معرض صور (Portfolio) بتصميم داكن مستوحى من كسوة الكعبة (أسود × ذهبي)، مبني بـ React و Tailwind CSS، ويعرض صورك **تلقائيًا** من مجلدات داخل `public` دون كتابة اسم أي صورة في الكود.

---

## 1) المتطلبات: تثبيت Node.js (مرة واحدة فقط)

1. افتح الموقع الرسمي: <https://nodejs.org>
2. حمّل النسخة **LTS** (الزر الأخضر) وثبّتها بالضغط على Next حتى النهاية.
3. للتأكد من نجاح التثبيت: افتح الطرفية (Terminal) واكتب:

```bash
node -v
```

إذا ظهر رقم إصدار مثل `v22.x.x` فكل شيء جاهز.

**كيف أفتح الطرفية داخل مجلد المشروع؟**

- **ويندوز:** افتح مجلد المشروع في مستكشف الملفات، اضغط على شريط العنوان في الأعلى، اكتب `cmd` ثم Enter.
- **ماك:** انقر بزر الفأرة الأيمن على المجلد ← Services ← New Terminal at Folder. (أو افتح Terminal واكتب `cd ` ثم اسحب المجلد إليه واضغط Enter).

---

## 2) تشغيل الموقع لأول مرة

داخل الطرفية المفتوحة على مجلد المشروع، نفّذ أمرين فقط:

```bash
npm install
npm run dev
```

- `npm install` يُنفَّذ **مرة واحدة فقط** (يحمّل مكتبات المشروع، قد يستغرق دقيقة).
- `npm run dev` يشغّل الموقع. سيظهر لك رابط مثل:

```
➜  Local:   http://localhost:5173/
```

افتح هذا الرابط في المتصفح. لإيقاف الموقع اضغط `Ctrl + C` في الطرفية.

---

## 3) إضافة صورك (القراءة التلقائية)

كل قسم في الموقع مربوط بمجلد داخل `public`:

| القسم في الموقع | المجلد |
| --- | --- |
| المسجد الحرام | `public/haram` |
| مناظر مكة | `public/mecca-gen` |
| ليليات | `public/night` |
| البروق | `public/lightning` |
| الشمس والقمر | `public/sky` |
| السعودية | `public/saudi` |
| صور دولية | `public/international` |
| بانوراميات | `public/pano` |
| درون | `public/drone` |
| تايم لابس | `public/timelapse` |

**الطريقة:** اسحب صورك إلى المجلد المناسب، ثم شغّل الموقع بـ `npm run dev` — ستظهر كلها تلقائيًا.

- الصيغ المدعومة: `jpg / jpeg / png / webp / avif / gif` وللفيديو (مناسب للتايم لابس): `mp4 / webm / mov`.
- أسماء الملفات حرّة (حتى العربية والمسافات تعمل)، لكن الترتيب أبجدي/رقمي — سمِّها `1.jpg`, `2.jpg`... إذا أردت التحكم بالترتيب.
- **أضفت صورًا والموقع شغّال؟** افتح طرفية ثانية في نفس المجلد ونفّذ `npm run photos` ثم حدّث صفحة المتصفح. (أو ببساطة أوقف الموقع بـ `Ctrl + C` وشغّله من جديد).

**كيف تعمل؟** المتصفح لا يستطيع قراءة محتويات المجلدات بنفسه، لذلك يوجد سكربت في `scripts/generate-manifest.mjs` يمسح المجلدات ويكتب قائمة الصور في `public/manifest.json`. هذا السكربت يعمل **تلقائيًا** قبل كل تشغيل (`npm run dev`) وقبل كل بناء (`npm run build`)، ثم تقرأه دالة `useGallery('اسم-المجلد')` في `src/hooks/useGallery.js` وتعرض كل شيء.

**لإضافة قسم جديد:** أنشئ مجلدًا جديدًا داخل `public` (مثلًا `portraits`) ثم أضف سطرًا في قائمة `categories` داخل `src/data/site.js`:

```js
{ id: 'portraits', label: 'بورتريه' },
```

## 4) تخصيص المحتوى وروابط التواصل

كل شيء في ملف واحد: **`src/data/site.js`**

1. **اسمك وبريدك:** عدّل قيم `name` و `email` في أعلى الملف.
2. **روابط التواصل:** في قائمة `socialLinks` استبدل كلمة `USERNAME` باسم حسابك في كل منصة:

```js
{ label: 'إنستغرام', url: 'https://instagram.com/USERNAME', icon: FaInstagram },
```

فمثلًا إن كان حسابك `@makkah_lens` يصبح الرابط `https://instagram.com/makkah_lens`.

3. **واتساب:** اكتب رقمك بالصيغة الدولية بدون `+` وبدون مسافات: `https://wa.me/9665XXXXXXXX`
4. **حذف منصة لا تستخدمها:** احذف سطرها كاملًا وستختفي الأيقونة من الموقع.
5. **إضافة منصة جديدة:** ابحث عن اسم أيقونتها في موقع <https://react-icons.github.io/react-icons/> (اختر مجموعة fa6)، أضفها لسطر الاستيراد `import { ... } from 'react-icons/fa6'` ثم أضف سطرًا جديدًا في `socialLinks`.

## 5) النشر المجاني على Vercel

### الطريقة الأسرع: من جهازك مباشرة (بدون GitHub)

1. أنشئ حسابًا مجانيًا في <https://vercel.com>
2. في الطرفية (داخل مجلد المشروع) نفّذ:

```bash
npm install -g vercel
vercel login
vercel --prod
```

3. `vercel login` سيفتح المتصفح لتسجيل الدخول.
4. سيطرح `vercel --prod` بضعة أسئلة — اضغط **Enter** لقبول الإجابة الافتراضية في كلها (سيتعرف تلقائيًا أنه مشروع Vite).
5. في النهاية يعطيك رابط موقعك: `https://اسم-مشروعك.vercel.app` 🎉

**لتحديث الموقع لاحقًا** (بعد إضافة صور أو تعديل): نفّذ `vercel --prod` مرة أخرى فقط.

### الطريقة الأفضل على المدى الطويل: عبر GitHub

1. أنشئ حسابًا في <https://github.com> ثم أنشئ مستودعًا جديدًا (New repository).
2. ارفع ملفات المشروع (اختر "uploading an existing file" واسحب الملفات — **لا ترفع مجلد `node_modules`**). أو استخدم برنامج GitHub Desktop لسهولة أكبر.
3. في Vercel: اضغط **Add New → Project** واختر المستودع ثم **Deploy**.
4. الميزة: كل مرة ترفع فيها تعديلًا إلى GitHub يتحدث الموقع تلقائيًا.

## 8) المزايا الجديدة

### أ) التمرير داخل المعرض
مرّر بإصبعك (جوال) أو بعجلة الفأرة/لوحة اللمس (كمبيوتر) وأنت فوق الصور مباشرة — تتنقل بين الصور أفقيًا. خارج منطقة المعرض، تمرير الصفحة رأسيًا يعمل كالمعتاد. لا يوجد "تكرار للدورة": يتوقف عند أول وآخر صورة، ويمكنك الرجوع للخلف بحرية.

### ب) الوصف التلقائي أسفل كل صورة
النص الصغير الذي يظهر أسفل يسار كل صورة يُستخرج تلقائيًا من **اسم الملف نفسه**. سمِّ صورك بأسماء وصفية بالشرطة أو الشرطة السفلية بدل الأرقام لتحصل على تعليق تلقائي:

- `غروب-الحرم.jpg` ← يظهر: "غروب الحرم"
- `1.jpg` أو `IMG_2044.jpg` ← لا يظهر أي تعليق (اسم غير وصفي)

### ج) الشعار بدل الاسم
ضع ملف شعارك في `public/logo.png` (يُفضّل PNG بخلفية شفافة، ارتفاع حوالي 80-120 بكسل). ثم افتح `src/data/site.js` وغيّر:

```js
logo: '/logo.png',
```

إن تركت `logo: ''` فارغة، يظهر اسمك النصي كما كان.

### د) عروض الطباعة (تبويب "عروض الطباعة")
يتيح للزائر اختيار إحدى صورك ومعاينتها كلوحة معلّقة داخل غرفة حقيقية (مكتب/مجلس/صالة).

**لتفعيله بصورك الخاصة:**
1. صوّر جدارًا فارغًا في مكانك (مكتب، مجلس، صالة...) بجودة جيدة
2. ضع الصورة في `public/mockups/` بنفس الاسم المحدد في `site.js` (مثلاً `office.jpg`)
3. افتح تبويب "عروض الطباعة" في الموقع، فعّل زر "إظهار دليل الإطار"، ثم عدّل الأرقام `top/left/width/height` (نسب مئوية) في `mockupRooms` داخل `site.js` حتى يطابق المربع الذهبي مكان الحائط الفارغ في صورتك

هذه نسخة أولى بسيطة؛ يمكن تطويرها لاحقًا لتشمل مقاسات طباعة، أسعارًا، وطلب شراء مباشر.

### هـ) آخر 3 أعمال من إنستغرام
تحديث يدوي بسيط — لا يتطلب أي إعداد تقني معقّد. كلما نشرت منشورًا جديدًا:

1. ضع نفس الصورة في `public/instagram/` (مثلاً `post-1.jpg`)
2. افتح `src/data/site.js` وحدّث `postUrl` بنسخ رابط المنشور من إنستغرام (زر "نسخ الرابط")

> **التحديث التلقائي بالكامل** (بدون تدخل يدوي) يتطلب ربط Instagram Graph API الرسمي من ميتا، الذي يحتاج حساب مطوّرين، رمز وصول (access token) يتجدد دوريًا، وخادمًا خلفيًا (serverless function) لتحديثه — خطوة أكبر يمكن إضافتها لاحقًا إن رغبت.

### و) نموذج التواصل (الاسم + الجوال + البريد + الرسالة)
الموقع الحالي بدون خادم خلفي، لذا يستخدم النموذج خدمة **Formspree** المجانية لإيصال الرسائل لبريدك مباشرة.

**التفعيل (5 دقائق):**
1. أنشئ حسابًا مجانيًا في https://formspree.io
2. أنشئ نموذجًا جديدًا (New Form)، واختر بريدك الإلكتروني لاستقبال الرسائل
3. انسخ الرابط الذي يعطيك إياه (يشبه `https://formspree.io/f/xxxxabcd`)
4. افتح `src/data/site.js` والصقه في:

```js
export const contactForm = {
  formspreeEndpoint: 'https://formspree.io/f/xxxxabcd',
}
```

قبل هذه الخطوة، النموذج سيعمل بصريًا لكن سيظهر تنبيهًا للزائر بأن الاستقبال غير مفعّل بعد بدل أن يتظاهر بالنجاح كذبًا.

---



ملفات الكاميرا الأصلية ضخمة (10–50 ميجابايت) وستجعل الموقع بطيئًا. قبل وضع الصور في المجلدات، صدّرها للويب:

- العرض الأطول: **2000–2560 بكسل** (وللبانوراميات حتى 4000).
- الصيغة: JPG بجودة ~80% أو WebP.
- هدفك: أقل من 800 كيلوبايت للصورة الواحدة تقريبًا.

يمكنك فعل ذلك من Lightroom/Photoshop عند التصدير، أو عبر موقع مجاني مثل squoosh.app.

## 7) مشاكل شائعة وحلولها

- **`'node' is not recognized` أو `command not found`:** لم يُثبَّت Node.js، أو تحتاج لإغلاق الطرفية وفتحها من جديد بعد التثبيت.
- **الصور لا تظهر:** تأكد أن اسم المجلد يطابق `id` القسم في `src/data/site.js` تمامًا، ثم نفّذ `npm run photos` وحدّث الصفحة.
- **`Port 5173 is in use`:** الموقع يعمل بالفعل في نافذة أخرى، أو سيقترح Vite منفذًا بديلًا تلقائيًا — استخدم الرابط الذي يظهر لك.
- **الأمر `vercel` غير معروف بعد التثبيت:** أغلق الطرفية وافتحها من جديد.

## بنية المشروع

```
mecca-portfolio/
├── public/                  ← ضع صورك هنا (المجلدات العشرة)
│   └── manifest.json        ← يتولد تلقائيًا، لا تعدّله يدويًا
├── scripts/
│   └── generate-manifest.mjs ← سكربت القراءة التلقائية للمجلدات
├── src/
│   ├── data/site.js         ← ★ ملف المحتوى: الاسم، النص، الأقسام، الروابط
│   ├── hooks/useGallery.js  ← الدالة التي تقرأ أي مجلد وتعيد محتوياته
│   └── components/          ← أجزاء الواجهة (Navbar, Hero, Gallery, Lightbox...)
├── index.html
└── package.json
```
